# 地面道具与技能清单

本文档记录当前游戏内地面随机刷新道具。所有道具在地面生成后默认存在 15 秒，未被拾取会消失；同一时间最多存在 4 个道具，常规刷新间隔为 5-8 秒。

## 通用生成规则

- 生成位置：地图内随机安全位置，避开墙体、玩家、其他道具和地图规则阻挡区。
- 拾取半径：道具基础拾取半径为 44，实际判定会叠加玩家半径。
- 初始刷新：开局后约 1.2-2.4 秒开始第一次刷新。
- 类型权重：回血包 30%，护盾 18%，疾跑 18%，脉冲 14%，过载 12%，磁吸 8%。

## 回血包

- 类型：生存道具。
- 图标/颜色：红色医疗十字。
- 效果：立即回复最大生命值的 22%。
- 限制：死亡玩家无法生效；生命值不会超过最大生命值。
- 用途：用于脱离交火后的续航，也能提高低血量玩家继续抢资源的容错。

## 护盾

- 类型：防御技能。
- 图标/颜色：蓝色盾牌。
- 持续时间：5 秒。
- 效果：获得 45 点护盾吸收量。
- 规则：受到伤害时优先消耗护盾吸收量；护盾持续时间和吸收量会按当前剩余值与新拾取值取更高值。
- 用途：适合进攻前抢节奏，或在被追击时吸收关键子弹。

## 疾跑

- 类型：机动/输出技能。
- 图标/颜色：橙色闪电。
- 持续时间：4 秒。
- 效果：移动速度提升 35%，射击冷却按 1.2 倍射速缩短。
- 规则：移动速度和射速加成会按当前效果与新拾取值取更高值。
- 用途：适合追击、抢道具、快速脱离陷阱区，也能在短时间内提高火力压制。

## 脉冲

- 类型：范围控制技能。
- 图标/颜色：紫色脉冲环。
- 生效方式：以拾取位置为中心连续释放 3 次脉冲，第一次立即触发，后续每 0.5 秒触发一次。
- 范围：每次半径 330。
- 效果：每次都会清除范围内所有子弹；对范围内其他玩家和地图生物造成 14 点伤害，并击退玩家 210 距离。
- 规则：不会伤害拾取者；丛林蟒蛇等地图生物也会受到脉冲伤害。
- 用途：适合解围、打断敌人弹幕、压制生物、把近身敌人弹出安全距离。

## 过载

- 类型：输出技能。
- 图标/颜色：红色准星。
- 持续时间：5 秒。
- 效果：子弹伤害提升 35%，子弹速度提升 10%。
- 规则：伤害与弹速加成会影响持续时间内发射的新子弹。
- 用途：适合在短窗口内打爆发，尤其适合对付低血量敌人或高生命地图生物。

## 磁吸

- 类型：资源控制技能。
- 图标/颜色：青绿色磁铁。
- 持续时间：6 秒。
- 效果：半径 280 内的地面道具会以 520 速度向玩家靠近。
- 规则：只吸引当前仍存在的道具；道具到达拾取范围后按原道具类型正常生效。
- 用途：适合快速滚雪球，或在危险区域外把道具拉出来。

## 实现位置

- 道具类型与生成权重：`scripts/arena/arena_root.gd`
- 道具数值：`scripts/config/game_balance.gd`
- 道具图标绘制：`scripts/gameplay/pickup.gd`
- 玩家身上的技能状态：`scripts/gameplay/player.gd`
